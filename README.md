
# PromptShield 🛡️

A source-aware security gateway for detecting prompt injection and data-exfiltration attempts in LLM workflows.

## Problem Statement
VORTEXA 3.0 — C-03

## Project Goals
- Detect direct prompt injection
- Inspect untrusted documents and tool outputs
- Apply ALLOW, BLOCK, SANITIZE, and ESCALATE decisions
- Record explainable security decisions
- Evaluate detection quality with reproducible tests

## Technology Stack
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite
- Testing: Pytest

Initial development.
